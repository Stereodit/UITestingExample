# UI Testing Example

Небольшое Android-приложение на Jetpack Compose: два экрана, на которых удобно показывать UI-тесты. Элементы размечены стабильными `testTag`. На корне включён `testTagsAsResourceId`, поэтому те же идентификаторы видны Compose-тестам и UiAutomator.

## Экраны

**Вход.** Email, пароль, показ пароля и кнопка «Войти». Пустые поля, некорректный email, короткий пароль и неверная пара дают отдельные ошибки. Ошибки объявляются как live region, заголовок экрана — как heading.

Демо-доступ: `demo@mail.com` / `Test1234`.

Email обрезается по краям и не зависит от регистра. Пароль сравнивается как есть: лишний пробел не проходит.

**Задачи.** После входа открывается список из 10 учебных задач. Можно добавить пункт, отметить его, отфильтровать («Все», «Активные», «Готовые»), прокрутить список и удалить пункт через диалог. «Выйти» возвращает на пустой экран входа и сбрасывает список.

## Тесты

| Где | Что проверяет |
| --- | --- |
| `app/src/test/.../LoginValidationTest.kt` | Правила входа без UI |
| `app/src/androidTest/.../LoginScreenTest.kt` | Ошибки полей, баннер доступа, переключатель пароля, переход на задачи |
| `app/src/androidTest/.../TasksScreenTest.kt` | Добавление, фильтры, пустой список, прокрутка, диалог удаления, выход |

Селекторы собраны в `app/src/main/java/com/example/uitestingexample/ui/TestTags.kt`. В тестах текст берётся из строковых ресурсов, а не зашит второй копией.

## Запуск

Откройте проект в Android Studio и запустите конфигурацию `app` на эмуляторе или устройстве.

Юнит-тесты:

```text
./gradlew testDebugUnitTest
```

UI-тесты (нужен запущенный эмулятор или устройство):

```text
./gradlew connectedDebugAndroidTest
```

Анимации в инструментальных тестах отключены через `testOptions.animationsDisabled`.
